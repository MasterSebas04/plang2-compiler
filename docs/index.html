The Story

SALAMIS (Sammy, Laith, Marcus, Including Sebastian) is named after its four founders, and it's so satisfying it'll make you hungry to code just by thinking about it. Think Python's clean syntax meets R's statistical power. SALAMIS sits right in between: more structured than R, more math-native than Python, with no (or at least minimal) compromises on either end.

SALAMIS is a statically typed language designed to make data, statistics, and probability-centered programming as easy as slicing salami. It's ready right out of the box. No longer will you need to import countless libraries for every little thing. It combines familiar tools like variables, functions, loops, and conditionals with support for vectors, matrices, probability distributions, simulation, plotting, and histograms; all with compile-time safety that catches type errors before they ruin your analysis.

Language Features

🔢

Types

Int, Float, Bool, Str, Vec<T>, Matrix<T>, and distribution types. Type annotations are optional. Types are inferred where possible.

🔀

Control Flow

If / else-if / else conditionals, range-based for loops, collection for loops, and while-style loops.

𝑓

Functions

Named functions with typed parameters and optional return type annotations. Functions are first-class and support the pipe operator |>.

📐

Vectors & Matrices

Vec and Matrix literals, element-wise arithmetic, matrix multiplication with @, and index/range slicing.

📊

Stats Builtins

mean, sum, min, max, std, len, plus standard math functions like sqrt, log, abs, sin, cos, pow, and more.

🎲

Distributions

Normal, Bernoulli, Poisson, and Uniform distributions. Sample from them with sample() or run repeated trials with simulate().

📁

CSV Data

Load CSV files as a Matrix<Float> with readCsv() and extract columns with col().

📈

Visualization

Line plots and histograms rendered as interactive HTML charts via Chart.js. No extra setup needed.

Static Checks

These errors are caught at compile time before any code runs.

✔ Variables must be declared before use
✔ No redeclaration in the same scope
✔ Assignment types must match the declared type
✔ Function calls must supply the correct number of arguments
✔ Argument types must match parameter types
✔ Return must appear inside a function
✔ Return type must match the declared return type
✔ If and while conditions must be Bool
✔ Matrix literals must have consistent row lengths, caught before any code runs
✔ @ operands must be Vec or Matrix
✔ plot and histogram require a Vec argument
✔ sample() only accepts a distribution value

3. Monte Carlo Simulation

let results = simulate(2000) {
    sample(Normal(0.0,1.0))
}
print("=== Normal(0,1) - 2000 samples ===")
print("Mean: " + format(mean(results), 4))
histogram(results)

4. Monte Carlo Pi Estimation

let hits: Float = 0.0
for i in (0..2000) {
    let x = sample(Uniform(0.0, 1.0))
    let y = sample(Uniform(0.0, 1.0))
    if x * x + y * y <= 1.0 {
        hits = hits + 1.0
    }
}
let pi_est = 4.0 * hits / 2000.0
print("Pi estimate: " + format(pi_est, 4))

Pi estimate: 3.1418

5. Descriptive Statistics and Normalization

let data: Vec<Float> = [2.0, 4.0, 4.0, 4.0, 5.0, 7.0, 9.0]

let lo = min(data)

6. CSV Data Analysis

let m = readCsv("prices.csv")
let prices = col(m, 1)
let volumes = col(m, 2)

let avg_price = mean(prices)
let lo_price = min(prices)
let hi_price = max(prices)

let norm_prices = (prices - lo_price) / (hi_price - lo_price)
plot(prices, norm_prices)
plot(volumes)

7. Birthday Paradox

fn one_trial() ~> Float {
    let bdays = simulate(100) {
        floor(sample(Uniform(0.0, 365.0)))
    }
    let result: Float = 100.0
    let found: Float = 0.0
    for k in (1..100) {
        if found == 0.0 {
            let bday_k = slice bdays(k)
            for j in (0..k) {
                if slice bdays(j) == bday_k {
                    if found == 0.0 {
                        result = k + 1.0
                        found = 1.0
                    }
                }
            }
        }
    }
    return result
}

let trials = simulate(100000) {
    one_trial()
}

print("Mean people needed: " + format(mean(trials), 2))
print("Min: " + format(min(trials), 0))
print("Max: " + format(max(trials), 0))
histogram(trials)
